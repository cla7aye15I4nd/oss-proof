# 发现：zlib-ng 中发现的问题

本工作在被验证提交的 zlib-ng `develop` 分支中发现了二十三个问题。每个都是 zlib-ng 自身的缺陷，可通过 `zlib.h`
有文档的函数触达，并由真实 C 代码的运行（消毒器无法发现时，由经跟踪的运行与 ISO C17 条文）展示。补丁 0003、0004、
0006、0007、0008、0009、0010、0011、0012、0013、0014、0015、0016、0017、0018、0019、0020、0021、0022、0023 与 0024 修复了前二十二个：每个问题一个补丁，只有补丁 0014
修复失败的 `gzwrite` 引起的两个问题（两者源于同一个过时指针）。最后一个问题（静态块打开时调用 `deflateReset`）给出错误结果但没有
内存错误，未打补丁。

证据一栏标明每个问题的展示方式。**公开 API**：只调用有文档的函数的程序（失败与设备来自普通的描述符），并在运行中看到缺陷：
消毒器报告或错误结果。**标准条文**：调用同样是有文档的函数，但没有消毒器报告该未定义行为，也没有任何异常表现；证据是把
ISO C17 的条文应用于经跟踪的运行。**白盒** 指由测试自行设置库的内部状态；这里没有问题依赖白盒测试。AddressSanitizer
指针对检查的报告，报告的是按标准条文未定义、但在平坦内存的目标上不会出错的行为。
